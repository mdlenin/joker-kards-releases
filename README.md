# Joker Kards — releases

Builds of **Joker Kards**, a desktop scoreboard for card and board game nights.

This repository holds only the built application and the files its updater
reads. The source is not here.

## Installing

Download the newest build from [Releases](../../releases):

- **macOS** — `joker-kards-<version>.dmg`. The app is not notarized, so macOS
  will say it cannot check it for malicious software: right-click the app and
  choose **Open**, once.
- **Windows** — `joker-kards-<version>-setup.exe`. SmartScreen will warn:
  **More info → Run anyway**.

After that, the app checks here for its own updates and offers them when they
appear. Nothing is installed until you say so.
